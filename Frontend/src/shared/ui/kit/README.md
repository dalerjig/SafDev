# Локальный UI-кит SafDev

Компоненты зависят только от React, TypeStyle и файлов этой папки.
Импорты прямые, без index.ts. Разметка экранов и данные чата остаются за пределами кита.

## С чего читать

1. theme.ts: тёмная и светлая палитры, CSS-переменные color, отступы space и скругления radius.
2. UiProvider.tsx: задаёт переменные темы и шрифт дочерним компонентам. mode выбирает dark или light; theme принимает частичные переопределения цветов поверх выбранной темы; locale задаёт lang контейнера. Переводов и переключателей пока нет.
3. Flow.tsx и Header.tsx: общая компоновка. Размер окна и колонки чата задаёт ChatLayout, а не провайдер.
4. Input.tsx, Textarea.tsx и Button.tsx: обычные HTML-контролы, оформленные через TypeStyle. Нативные props передаются внутрь.
5. ListItem.tsx: строка с icon, title, description, label, selected и необязательным onSelect. О сущностях чата ничего не знает.
6. Icon.tsx: три текущие иконки user/search/more через CSS. Tooltip.tsx: подсказка для кнопки при наведении и фокусе.

Компонент объявляется через const, затем export default, затем стили.
Inline style используется только для значений CSS-переменных темы, gap и размера иконки.
Новые варианты и компоненты добавляются по реальной потребности.

## Использование

App подключает UiProvider с mode="dark". Для светлой темы достаточно заменить значение на mode="light". Переключатель в интерфейсе пока не добавлен.

ChatItem использует ListItem; ChatList — Input;
Conversation — Header, Flow, Icon, Button и Textarea.
Кнопки поиска и информации, а также поле поиска остаются без логики. Выбор диалога и локальная отправка реализованы в ChatPage и виджетах, за пределами кита. Моки сохранены.

## Будущий отдельный пакет

Вынести содержимое папки, подключить React как peer dependency, настроить сборку и экспорты.
Текущие файлы не используют алиас @/, ассеты приложения или зависимости от его страниц.
Сборка пакета и публикация сейчас не настроены.
