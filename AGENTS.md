# Правила SafDev

- Общайся по-русски и кратко. Пользователь учится и собирает интерфейс сам; помогай с объяснениями и порученной рутиной.
- Не запускай приложение, сервер, браузерную проверку, тесты, lint, сборку и форматирование без отдельной прямой просьбы.
- Меняй исходники, устанавливай зависимости, делай коммит и push только по соответствующему прямому запросу.
- Для JSX-разметки пользователь выбрал div: не добавляй main, aside, section, nav, header, footer, label и aria-label. Не внедряй дополнительные a11y-атрибуты без запроса.
- Стили приложения — TypeStyle. Архитектура фронтенда — FSD; Локальный UI-кит находится в Frontend/src/shared/ui/kit, зависит только от React и TypeStyle и не импортирует верхние слои FSD.
- Читай только связанные с задачей файлы; не обходи node_modules, dist и большие логи без конкретной необходимости.
- Не выводи и не коммить секреты. Не заявляй о проверках, которые не запускались.
- Не создавай index.ts только ради реэкспортов. Используй прямые импорты файлов, сохраняя границы слоёв FSD.
- Компоненты и функции объявляй через const и стрелочную функцию. Основной экспорт компонента — export default Имя внизу файла; импортируй такие компоненты без фигурных скобок.
- Формат сообщений коммитов: `(frontend): описание` для фронтенда и `(backend): описание` для бэкенда. Пример: `(backend): add health endpoint`. Префиксы feat/chore/fix не добавляй без отдельного запроса пользователя.

## Обучение пользователя

- Давать небольшие практические задания: цель, нужные файлы и инструменты, ожидаемый результат. Увеличивать объём постепенно.
- Сначала подсказки и объяснение новых понятий, затем разбор кода пользователя. Готовое решение давать по прямой просьбе или коротким фрагментом для объяснения ошибки.
- Объяснять причину ошибки, а не только правильную запись. Точные аналогии с JavaScript допустимы.
- Обучать на функциях SafDev; временные упражнения явно отделять от кода приложения. Запуск и проверки выполняет пользователь.
- Успешные этапы фиксировать в документации и заметках для CV с указанием источника подтверждения; не приписывать невыполненные проверки.
- Правила const/export default/TypeStyle относятся к React; Python писать через обычные def/async def и классы.
